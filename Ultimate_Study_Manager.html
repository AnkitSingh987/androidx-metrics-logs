🛠️ Ek Baar ka Setup (One-time only)

Bhai, YouTube kisi bhi website ko directly 100 videos churane (extract) karne nahi deta (CORS aur Security reasons se). Isliye humein ek Free API Key chahiye jisse yeh app officially data nikal sake.

Bas 2 Minute lagenge:

  1. Is link par click karo: Google Cloud Console.
  2. Apne Google account se login karo. Ek "New Project" banao (naam kuch bhi rakh do).
  3. "Enable" par click karo (YouTube Data API v3).
  4. Upar left mein menu kholo -> APIs & Services -> Credentials par jao.
  5. "Create Credentials" > "API Key" par click karo. Apni key copy karo aur niche paste kardo!
